Set the default width and height as percentages to define the initial target frame size. Once you save a custom size, that value will be used in all future sessions instead of the factory default.

Target mode allows you to define a rectangular frame within the camera preview where OCR recognition will focus. Instead of processing the entire camera view, the AI model analyzes only the target region, reducing false detections from background elements and improving performance on the desired text area.

You control the size of the target frame using two settings: Width and Height (as percentages of the screen). The frame is always centered on the screen. These values define the default frame size. Once you adjust and save them, your last saved values will automatically be applied every time you start a session— so you never have to reconfigure for your typical use case.

Target Mode Settings

Width Percentage (10% – 100%)

  • What it is: The default target frame width as a percentage of the screen width.
  • 10% – Very narrow, for scanning thin labels or single-column text
  • 50% – Half the screen width, suitable for standard document or barcode scanning
  • 100% – Full screen width; effectively no horizontal cropping
  • Your last saved value will be restored automatically on next launch.

Height Percentage (5% – 100%)

  • What it is: The default target frame height as a percentage of the screen height.
  • 10% – Thin horizontal strip, ideal for reading single lines of text
  • 30% – Factory default, captures a moderate text area without excessive background
  • 60% – Large area, useful for multi-line text or product labels
  • 100% – Full screen height; no vertical cropping
  • Your last saved value will be restored automatically on next launch.

Recommendation:

  • Factory defaults: 60% width, 30% height. This provides a good balance for typical barcode and label scanning. These are used the very first time, or after restoring defaults.
  • For single-line barcodes: Reduce height to 15–20% and keep width at 70–80%.
  • For multi-line text or receipts: Increase height to 50–70% and keep width at 80–90%.
  • For shelf product labels: Use a moderate frame (50–70% width, 40–50% height).
  • Test and iterate: Adjust width and height, save, and reopen to confirm your saved frame persists across sessions.

Tip: When target mode is active, the frame overlay on the camera preview shows exactly what area will be processed. Tap or drag the preview to hide the instruction text and see the live target frame more clearly. Adjust the width and height until the entire text you want to recognize fits comfortably within the frame, with minimal background around it. Once saved, your frame size is remembered — you won't need to re-adjust it next time you open the app. Use Restore to Default Settings to reset back to the factory defaults at any time.

Common Use Cases:

  • Barcode scanning at checkout: 70% width, 20% height
  • Receipt scanning: 85% width, 60% height
  • Shelf label reading: 60% width, 40% height
  • Document form filling: 90% width, 70% height
  • QR code scanning: 50% width, 50% height
